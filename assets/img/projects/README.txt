Put your project images here, then point to them from data/portfolio.json.

  "image": "assets/img/projects/qibla-finder.png"   ← portrait screenshot, shown inside the phone frame
  "icon":  "assets/img/projects/qibla-finder-icon.png" ← square app icon (512×512)

Screenshot size: about 1080×2340 (a normal phone screenshot works). Use .webp or .png and keep each file under ~300 KB.
Leave "image": "" and the site draws a coloured placeholder screen using "color".
File names: lowercase, no spaces (qibla-finder.png, not "Qibla Finder.png").
